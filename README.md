# FINPILOT AI

Personal finance foundation: track income, expenses and loans, then see a dashboard with deterministic calculations. The browser talks only to Next.js; Next.js proxies `/api/*` to Express. Express owns JWT auth, Prisma and PostgreSQL.

This stage does **not** include AI chat, market data, goals or investments.

## Stack

- `apps/web` — Next.js (App Router), React, TypeScript, Tailwind, Chart.js
- `apps/api` — Express, Prisma, JWT (access + refresh), bcrypt, Zod
- `packages/shared` — types, category constants, financial engine
- PostgreSQL 16 via Docker Compose

## Run locally

From the repo root (`Major`), one command starts Postgres, applies migrations, then runs the API and the Next.js app:

```bash
npm start
```

(`npm run dev` does the same.) On Windows you can also double-click `start.bat`.

Docker Desktop must be running. First run may take a minute while images pull.

- App: http://localhost:3000
- API: http://localhost:4000/health

If `node_modules` is missing, the script runs `npm install` first. Env files are created automatically when they do not exist.

Default env files:

- `apps/api/.env` — `DATABASE_URL`, JWT secrets, `PORT=4000`
- `apps/web/.env.local` — `API_INTERNAL_URL=http://localhost:4000`

## Auth

- Register / login via the UI
- Passwords hashed with bcrypt
- Short-lived access JWT (sessionStorage) and httpOnly refresh cookie (set by the Next.js BFF)
- Every query is scoped to `req.user.id`

## Financial engine

Pure functions in `packages/shared/src/finance.ts` (savings, savings rate, loan progress, rule-based health score). The API analytics routes and the dashboard charts use these numbers — they are not generated by an LLM.
